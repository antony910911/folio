架一份只屬於你的 Folio

Folio 是一個可以用 Apple Pencil 手寫、打字、畫心智圖，還能在 iPad、手機、電腦之間同步的筆記 App。照著這份教學一步一步做，你就會有一份完全屬於自己的 Folio。不用會寫程式。

  • ⏱ 大約 30 分鐘
  • 💰 全部免費
  • 💻 建議用電腦設定
  • 🔒 筆記只有你看得到

先搞懂：我們要做什麼？

你可以把整件事想成「開一間自己的店」：

📦 GitHub＝倉庫放 Folio「程式碼」的地方。你會從原作者的倉庫複製一份到自己的倉庫（這個動作叫 Fork）。
🏪 Cloudflare＝店面讓 Folio 變成一個網址，任何裝置打開就能用。它會自動從你的倉庫拿程式碼來「開店」（叫做部署）。
🔑 同步密碼＝店的鑰匙你自己訂的一組密碼。iPad、手機、電腦都輸入同一組，筆記就會互相同步。不要給別人。
🤖 Claude＝助理（選用）手寫轉文字會用到；你也可以請它幫你改 Folio 的功能。不用也完全可以正常使用。
做完之後你的 Folio 和原作者的是兩份完全分開的 App：你看不到他的筆記，他也看不到你的。
開始前準備好
  • 一個常用的 Email（會收到驗證信）
  • 一台電腦（用 iPad 也可以，只是畫面比較小、按鈕比較難找）
  • 想好一組同步密碼：至少 8 個字，可以用英文、數字、符號或中文，記在安全的地方

1. 申請 GitHub 帳號 約 5 分鐘

已經有 GitHub 帳號的話，登入後直接跳到第 2 步。

1

打開 github.com/signup。

2

依序填入 Email、密碼、使用者名稱（英文，之後會出現在網址裡，例如 amy-notes），按 Continue 或 Create account。

3

可能會要你玩一個小驗證（選圖片之類的），證明你不是機器人。

4

去信箱收 GitHub 寄來的驗證碼，填回網頁。

5

接下來如果問你一些問卷問題（用途、團隊人數），可以直接按 Skip personalization 跳過。方案選免費（Free）就好。

✅ 完成的樣子畫面右上角有你的頭像圓圈，代表已經登入。

2. 複製一份 Folio 給自己（Fork） 約 2 分鐘

1

確定已經登入 GitHub，打開原作者的 Folio 倉庫：

https://github.com/antony910911/folio
2

在頁面右上方找到 Fork 按鈕（旁邊有一個分岔的小圖示），按下去。

用手機看找不到？手機版畫面比較擠，可以把網頁往右滑一點，或改用電腦。
3

會出現「Create a new fork」的頁面。什麼都不用改，Repository name 保持 folio，直接按最下面綠色的 Create fork。

✅ 完成的樣子網址變成 github.com/你的使用者名稱/folio，標題下面有一行小字「forked from antony910911/folio」。這就是你自己的倉庫了。

3. 申請 Cloudflare 帳號 約 3 分鐘

1

打開 dash.cloudflare.com/sign-up，填 Email 和密碼，按 Sign up。

2

到信箱點 Cloudflare 寄來的驗證連結。

3

登入後如果問你要做什麼（網域、網站之類），都可以跳過或關掉。不需要買網域，也不需要信用卡。

✅ 完成的樣子看到 Cloudflare 的後台，左邊有一排選單。

4. 把 Folio 放到網路上（部署） 約 5 分鐘

1

在 Cloudflare 後台左邊選單找到 Workers & Pages，點進去。
（有時候它藏在 Compute (Workers) 底下，展開就看得到。）

2

按 Create application（或 Create）。

3

在「Import a repository」旁邊按 Get started。

4

第一次會要你連接 GitHub：按 Connect GitHub（或選 GitHub 帳號），會跳到 GitHub 的授權頁面。

  1. 選 Only select repositories（只給 Cloudflare 看指定的倉庫，比較安全）。
  2. 在下拉選單選 folio。
  3. 按 Install & Authorize，可能要再輸入一次 GitHub 密碼。
5

回到 Cloudflare，在倉庫清單裡點 folio。

6

會出現設定頁面，大部分都不用改，只要確認這幾項：

  • Project name（專案名稱）：一定要是 folio，不要改成別的。
  • Build command（建置指令）：留空白。
  • Deploy command（部署指令）：保持預設的 npx wrangler deploy。

然後按 Deploy（或 Save and Deploy）。

7

等 1～3 分鐘，畫面會顯示部署進度。看到成功（Success／綠色勾勾）就好了。

第一次用 Cloudflare？它可能會請你取一個 workers.dev 子網域名稱（例如 amy），這會變成你網址的一部分。取一個你喜歡的英文名字就好。
✅ 完成的樣子你會看到一個網址，長得像：
https://folio.你的子網域.workers.dev
點下去看到 Folio 的畫面，就代表成功了！把這個網址記下來，之後每台裝置都用它。

5. 設定同步密碼 約 2 分鐘

這一步是讓 iPad、手機、電腦的筆記可以互相同步。不設定的話，每台裝置的筆記會各自分開。

1

在 Cloudflare 的 Workers & Pages 裡點 folio。

2

上方分頁選 Settings，往下找到 Variables and Secrets，按旁邊的 Add。

3

填這三格：

  • Type（類型）：選 Secret。⚠️ 一定要選 Secret，不要選 Text。
  • Variable name（名稱）：完全照抄，大小寫要一樣：
    SYNC_TOKEN
  • Value（值）：你自己想好的同步密碼。
4

按 Deploy（或 Save）讓設定生效。

為什麼一定要選 Secret？選 Text 的話，之後每次更新 Folio 時這個密碼都可能被清掉，App 左下角就會跳出「伺服器上的同步密碼不見了」。
🔑 同步密碼就是你筆記的鑰匙知道這組密碼的人，就能看到、也能修改你所有的筆記。不要傳給別人，也不要在別人的裝置上輸入。

6. 裝到 iPad、手機、電腦 每台約 2 分鐘

iPad／iPhone

1

用 Safari 打開你的 Folio 網址（https://folio.你的子網域.workers.dev）。

2

按畫面上的分享按鈕（方框加一個向上箭頭），往下滑，選 加入主畫面，再按 新增。

3

回到主畫面，點新出現的 Folio 圖示打開（之後都從這裡開，不要從 Safari 開）。

為什麼要加到主畫面？只用 Safari 開的話，太久沒用時 Safari 可能會清掉資料。加到主畫面的 Folio 不會被這樣清。

開啟同步（每台裝置都要做一次）

1

打開 Folio，按左上角的方框圖示打開側邊欄，點最下面的「開啟跨裝置同步」。

2

輸入你在第 5 步設定的同步密碼（可以勾「顯示密碼」檢查有沒有打錯），按 開啟同步。

3

第二台以後的裝置會問你「雲端已經有筆記了」，新裝置選「使用雲端的筆記」。

✅ 完成的樣子側邊欄最下面顯示「已同步」。在 iPad 寫一個字，1～2 秒後手機上就會出現。

電腦

用 Chrome、Edge 或 Safari 打開同一個網址，一樣開啟同步就好。想要像 App 一樣有自己的視窗：Chrome／Edge 網址列右邊有一個「安裝」小圖示可以按。

7. 手寫轉文字 選用・需要付費

Folio 可以把你的手寫字轉成打字的文字，這個功能是請 Claude（Anthropic 公司的 AI）幫忙讀字的，需要一把「API 金鑰」，費用按使用量計算（辨識一段手寫通常不到台幣 1 元）。

不想花錢？iPad 有內建的免費功能「隨手寫」：在 Folio 的文字框裡直接用 Apple Pencil 寫字，iPad 會自動轉成文字（iPad 的 設定 › Apple Pencil › 隨手寫 要打開）。
1

打開 console.anthropic.com，註冊並登入。

2

到 Billing（帳單）儲值一點金額（例如 5 美元，可以用很久）。

3

到 API Keys 按 Create Key，名字隨便取（例如 folio），按建立後馬上複製那串 sk-ant- 開頭的金鑰（它只會顯示這一次）。

4

回到 Folio，按右上角 ⋯ › 辨識設定，貼上金鑰、儲存。

5

之後用「選取」工具框住手寫，按「轉成文字」就可以了。

金鑰跟錢包一樣金鑰只會存在你輸入的那台裝置上。不要給別人，也不要在別人的裝置上輸入。

8. 之後怎麼更新到新版 約 1 分鐘

原作者之後加了新功能，你的 Folio 不會自動跟著更新（因為是你自己的一份）。想更新的時候：

1

登入 GitHub，打開你自己的倉庫 github.com/你的使用者名稱/folio。

2

如果有新版，會看到一行「This branch is X commits behind…」。按旁邊的 Sync fork，再按綠色的 Update branch。

3

Cloudflare 會在 1～3 分鐘內自動重新部署。之後把 iPad 上的 Folio 完全關掉再打開一兩次，就是新版了。

你的筆記不會受影響更新的只是 App 本身，筆記存在你的裝置和你的 Cloudflare 裡，不會被覆蓋。

9. 請 Claude 幫你改功能 進階・選用

想要 Folio 多一個功能、換個顏色？可以直接用中文跟 Claude 說，它會幫你改好你自己的那一份：

1

打開 claude.ai/code，登入 Claude 帳號（需要付費方案）。

2

照畫面指示連接 GitHub，選你自己的 你的使用者名稱/folio 倉庫。

3

用平常說話的方式描述你要什麼，例如：

我想在 Folio 的工具列加一個「插入今天日期」的按鈕，按下去會在頁面新增一個寫著今天日期的文字框。改好之後幫我推到 main。
4

Claude 改好、推上 GitHub 後，Cloudflare 會自動部署。重開 Folio 就能看到。

改之前先備份在 Folio 按 ⋯ › 匯出備份 存一份檔案。萬一改壞了，筆記還在。
你改的只是你自己那一份，不會影響原作者的 Folio。

卡住了怎麼辦

部署失敗，訊息有「name … must match」

第 4 步的 Project name 不是 folio。到 Cloudflare 把剛剛建立的 Worker 刪掉（Worker › Settings › 最下面 Delete），再照第 4 步重做一次，名稱保持 folio。

打開網址顯示「No URLs enabled」或找不到網頁

到 Cloudflare 的 folio › Settings › Domains & Routes，把 workers.dev 那一列打開（Enable）。等一兩分鐘再試。

Folio 左下角說「伺服器還沒有設定同步密碼」或「同步密碼不見了」

回到第 5 步檢查：名稱是不是完全是 SYNC_TOKEN（大寫、底線）、類型是不是 Secret、最後有沒有按 Deploy。改好後在 Folio 重新輸入一次同步密碼。

Folio 說「同步密碼不對」

勾「顯示密碼」看看有沒有打錯，大小寫、全形半形都要一樣。真的忘記的話，回到第 5 步把 SYNC_TOKEN 改成新密碼，再到每台裝置重新輸入。

「連不上同步伺服器」

確認網路正常，而且是從你自己的網址（folio.你的子網域.workers.dev）打開 Folio，不是從別的地方。

iPad 上看不到新功能

把 Folio 從背景完全關掉（從螢幕下方往上滑，把 Folio 往上滑掉），再打開一兩次。按右上角 ⋯，面板最下面會顯示版本號。

把問題丟給 Claude
