# Folio

自己的筆記本。結構跟 OneNote 一樣是「筆記本 › 分區 › 頁面」，每一頁都是一張可以自由寫字、打字的紙，iPad 上可以用 Apple Pencil 手寫。

目前有：手寫、文字框、心智圖、匯入 PDF／簡報／圖片、手寫轉文字、匯出 PowerPoint／Word、跨裝置同步（Cloudflare）。

## 現在能做什麼

| 功能 | 說明 |
|---|---|
| 筆記本、分區、頁面 | 新增、重新命名、刪除、上移下移；分區可以換顏色；頁面可以移到別的分區 |
| 手寫 | 筆和螢光筆，各 5 種顏色、3 種粗細。Apple Pencil 有筆壓；滑鼠和手指用速度模擬粗細 |
| 防誤觸 | 第一次用 Apple Pencil 寫字後，手指自動改成捲動頁面，手掌放在螢幕上也不會畫到。可以在「⋯」裡切換 |
| 文字框 | 點頁面任何位置新增；拖曳上方橫條移動，右邊把手調整寬度；支援 ⌘B／⌘I／⌘U |
| 選取 | 框選或點一下筆跡；可以移動、複製、刪除 |
| 橡皮擦 | 碰到的整條筆跡會被擦掉 |
| 縮放平移 | 兩指捏合、兩指拖曳；電腦上用滾輪捲動、Ctrl 加滾輪縮放、按住空白鍵拖曳 |
| 頁面背景 | 空白、橫線、方格、點點 |
| 復原 | 每頁最多 100 步 |
| 匯入 PDF／簡報 | 工具列的圖片按鈕，或把檔案拖進頁面。每一頁變成一張圖片，可以直接用筆在上面寫。可以選「全部放在這一頁」（由上往下排）或「每一頁建立一個新頁面」，也可以只匯入部分頁數（例如 `1-5, 8`）。PowerPoint／Keynote 請先另存成 PDF |
| 插入圖片 | PNG、JPEG、WebP、GIF：用圖片按鈕、拖放，或直接貼上截圖。選取圖片後拖曳右下角的圓點可以等比例縮放 |
| 心智圖 | 工具列的心智圖按鈕。點節點選取、再點一次編輯文字；下方工具列可以加子主題、同層主題、上下移、收合、刪除。拖曳中心主題移動整張圖。分支多的時候會自動分到左右兩邊。可以直接用筆在上面畫 |
| 文字框轉心智圖 | 選取一個文字框，點「轉成心智圖」：第一行是中心主題，用縮排（空白、Tab）或項目符號表示層級 |
| 手寫轉文字 | 用「選取」框住手寫後點「轉成文字」，或「⋯ › 整頁手寫轉文字」。靠得近的筆跡會合成一段，每段變成一個文字框；按復原可以換回手寫 |
| 匯出 PowerPoint | 「⋯ › 匯出」可以匯出這一頁或整個分區。版面照原樣擺，文字可以在 PowerPoint 裡繼續改，手寫是透明背景的圖片。頁面太長會自動切成好幾張投影片 |
| 匯出 Word | 依閱讀順序由上到下排：文字變成段落（保留粗體、斜體、底線、清單），手寫變成圖片，心智圖變成多層項目符號的大綱。左右並排的版面會變成上下排；螢光筆不會匯出 |
| 備份 | 「⋯ › 備份檔」存成 .json；「匯入備份…」可以搬到另一台裝置 |

快速鍵：`V` 選取、`H` 平移、`P` 筆、`M` 螢光筆、`E` 橡皮擦、`T` 文字、`⌘Z`／`⇧⌘Z` 復原重做、`⌘D` 複製、`Delete` 刪除選取、`Esc` 離開文字框。

心智圖選取節點時：`Tab` 加子主題、`Enter` 加同層主題、`空白鍵`／`F2` 編輯、`Delete` 刪除、方向鍵移動選取、`Alt+↑↓` 調整順序、`Esc` 取消選取。編輯文字時 `Enter` 完成（中文輸入法選字時按的 Enter 不算）、`Tab` 完成並加子主題、`Shift+Enter` 換行。

## 部署到 Cloudflare（含跨裝置同步）

App 和同步伺服器放在同一個 Cloudflare Worker。免費方案就夠個人使用。

1. Cloudflare 後台 › **Workers & Pages** › **Create** › **Import a repository**，選 `folio` 這個 repo。設定都用預設值（部署指令是 `npx wrangler deploy`，會讀 `wrangler.jsonc`）。之後每次推到 `main` 都會自動部署。
2. 第一次部署完成後，到這個 Worker 的 **Settings › Variables and Secrets** › **Add**：類型選 **Secret**，名稱 `SYNC_TOKEN`，值是你自己的同步密碼（至少 12 個字，只能用英文字母、數字和 `. _ ~ -`；可以用密碼管理工具產生的強密碼）。
3. 在 iPad 的 Safari 打開 `https://folio.<你的子網域>.workers.dev`，按分享 › **加入主畫面**。
4. 點側邊欄最下面的「開啟跨裝置同步」，輸入同一組同步密碼。
5. 其他裝置也打開同一個網址、輸入同一組密碼。第一次會問要「使用雲端的筆記」（新裝置選這個）還是「合併兩邊」。

加入主畫面很重要：沒加的話，Safari 可能會在一段時間沒用後清掉本機資料。開了同步之後，就算本機資料被清掉也能從雲端拿回來。

在 claude.ai 預覽裡寫的筆記不會自動出現在新網址：先在預覽裡「⋯ › 備份檔」，再到新網址「⋯ › 匯入備份…」，開了同步的話會一起傳上雲端。

## 跨裝置同步怎麼運作

- 每台裝置都先存在本機，沒網路時照常可以用；連上網後自動把變更送出、把別台的變更拿回來。
- 裝置之間用 WebSocket 即時通知，另一台的修改通常 1～2 秒內就會出現。
- 同步的單位很細：每一筆筆跡、每個文字框、每張心智圖、每張圖片各自一筆。所以兩台裝置同時在同一頁寫字，兩邊的字都會保留。
- 同一個項目兩邊都改了（例如同一個文字框），以**比較晚的修改**為準。
- 正在寫字或打字的那一頁，會等你停下來才套用別台的修改，不會打斷你。
- 圖片用內容的雜湊當 id：同一張圖只上傳一次；別台裝置需要時才下載，下載後離線也看得到。
- 側邊欄最下面會顯示同步狀態（已同步、同步中、離線中、密碼不對）。

### 免費方案的額度

| 項目 | 免費上限 | 換算 |
|---|---|---|
| Worker 請求 | 每天 10 萬次 | 網頁本身的檔案不算 |
| Durable Objects 儲存 | 總共 5 GB | 筆記和圖片都放這裡；投影片一頁大約 100～300 KB |
| Durable Objects 寫入 | 每天 10 萬列 | 一筆筆跡大約 2～3 列 |

超過時當天的同步會失敗，隔天（UTC 00:00）恢復，本機資料不受影響。

### 安全

- 同步密碼存在每台裝置的瀏覽器裡。知道密碼的人就能讀寫你的筆記，請不要在別人的裝置上輸入。
- 換密碼：在 Cloudflare 改 `SYNC_TOKEN`，再到每台裝置的「跨裝置同步…」輸入新密碼。
- App 的網頁檔案是公開的（裡面沒有個人資料）；筆記只能透過 `/api/` 存取，一定要帶密碼。

iPad 上匯出檔案時會打開分享選單，選「儲存到檔案」或直接傳到 PowerPoint、Word、AirDrop。

## 手寫辨識

辨識時，手寫筆跡會畫成圖片傳給 Claude（`claude-opus-5-5`）讀成文字。逐字轉寫不需要深入思考，所以用 `effort: low`；也開了 `fallbacks: "default"`，被安全機制擋下時會自動改用其他模型再試。

- **自己架的 App**：到「⋯ › 手寫辨識設定」填入 Anthropic API 金鑰（console.anthropic.com 申請）。費用從你的 API 帳戶扣，金鑰只存在那台裝置的瀏覽器裡，請不要在別人的裝置上填。
- **在 claude.ai 預覽裡**：直接用你的 Claude 帳號辨識，不需要金鑰，第一次會先問你是否允許。
- **iPad 內建的「隨手寫」**：在文字框裡直接用 Apple Pencil 寫字，iPadOS 會轉成文字，不用網路也不用金鑰（設定 › Apple Pencil › 隨手寫）。

## 在電腦上開發

不需要安裝任何套件，也沒有建置步驟。

```sh
npm install    # 只有本機跑同步伺服器（wrangler）時需要
npm run dev    # App 加同步伺服器，在 http://127.0.0.1:8787 開啟；同步密碼寫在 .dev.vars（SYNC_TOKEN=...）
               # 本機的同步資料放在上一層的 .folio-dev-state（放在專案裡會讓 wrangler 一直重新載入）
npm start      # 只開 App（不含同步），在 http://localhost:8080
npm test       # 跑單元測試（Node 20 以上）
```

### 資料格式

- 筆記本 `{ id, name, order }`
- 分區 `{ id, notebookId, name, color, order }`
- 頁面 `{ id, sectionId, title, background, order, createdAt, updatedAt }`
- 頁面內容 `{ id, items: [...] }`，打開頁面時才讀取
  - 筆跡 `{ type: 'stroke', tool: 'pen' | 'highlighter', color, size, points: [[x, y, 筆壓], ...] }`
  - 文字框 `{ type: 'text', x, y, w, html }`
  - 心智圖 `{ type: 'mindmap', x, y, root }`，節點 `{ id, text, children, collapsed? }`；(x, y) 是中心主題的位置，排版每次重新算
  - 圖片 `{ type: 'image', x, y, w, h, asset }`，圖片檔另外存在 `assets`（`{ id, blob, w, h }`），沒有頁面用到的圖片會在下次開啟時清掉

頁面清單和頁面內容分開存，之後做同步時可以只傳有變動的頁面。
